# n8n Workflows — Build Guide

**Untuk:** Developer (you)
**Prereq:** n8n running di `http://localhost:5678`, zuckcannon running di `http://localhost:6969`

---

## Sebelum Mulai: Setup Credentials + Variables

### 1. Telegram Bot

1. Buka Telegram → cari **@BotFather** → `/newbot`
2. Ikuti instruksi → dapat `BOT_TOKEN` (format: `123456:ABCdef...`)
3. Kirim pesan ke bot lo, lalu buka:
   `https://api.telegram.org/bot{BOT_TOKEN}/getUpdates`
4. Catat `chat.id` dari response → ini `CHAT_ID` lo

### 2. n8n Variables

Buka n8n → **Settings → Variables** → tambah:

| Name | Value |
|------|-------|
| `TELEGRAM_BOT_TOKEN` | token dari BotFather |
| `TELEGRAM_CHAT_ID` | chat ID lo |
| `ZUCKCANNON_URL` | `http://localhost:6969` |

### 3. n8n Credentials

Buka **Credentials → Add Credential**:

Tidak perlu credential khusus — semua request ke localhost dan Telegram pakai URL langsung dengan token di query param/body.

## Workflow 1: Rules Engine Loop

**Trigger:** Every 2 minutes
**Purpose:** Pull active rules dari zuckcannon → evaluate kondisi vs FB data → pause/scale jika triggered → Telegram alert → log

---

### Node 1 — Schedule Trigger

- Type: **Schedule Trigger**
- Trigger interval: **Every 2 Minutes**

---

### Node 2 — Get Active Rules

- Type: **HTTP Request**
- Name: `Get Active Rules`
- Method: `GET`
- URL: `{{ $vars.ZUCKCANNON_URL }}/api/rules-engine/active-rules`
- Response format: `JSON`

> Ini return array of rules. Setiap rule sudah include `entities[]` (flat list campaign IDs) dan `token` (System User token).

---

### Node 3 — Split Rules

- Type: **Split In Batches**
- Name: `Split Rules`
- Batch Size: `1`

---

### Node 4 — Build FB Batch Request

- Type: **Code**
- Name: `Build FB Batch`
- Language: JavaScript

```javascript
const rule = $input.item.json;
const entities = rule.entities || [];
const token = rule.token;

if (!token) {
  return [{ json: { skip: true, reason: 'No token', rule } }];
}

if (entities.length === 0) {
  return [{ json: { skip: true, reason: 'No entities', rule } }];
}

// Build FB batch request — one insights call per entity
const batch = entities.map(entityId => ({
  method: 'GET',
  relative_url: `${entityId}/insights?fields=spend,actions,action_values,purchase_roas,cost_per_action_type&date_preset=today`,
}));

return [{ json: { rule, token, batch, entities } }];
```

---

### Node 5 — Skip if No Data (IF)

- Type: **IF**
- Name: `Has Data?`
- Condition: `{{ $json.skip }}` **is not** `true`
- True branch → Node 6
- False branch → (end, do nothing)

---

### Node 6 — Call FB Batch API

- Type: **HTTP Request**
- Name: `FB Batch API`
- Method: `POST`
- URL: `https://graph.facebook.com/v21.0/`
- Authentication: None
- Body Content Type: `Form Data`
- Fields:
  - `batch`: `{{ JSON.stringify($json.batch) }}`
  - `access_token`: `{{ $json.token }}`
- Options → Response: `JSON`

> FB Batch API return array. Index ke-N = response untuk entity ke-N di `batch`.

---

### Node 7 — Evaluate Conditions

- Type: **Code**
- Name: `Evaluate Rules`
- Language: JavaScript

```javascript
// Get rule + entities dari node sebelumnya
const { rule, entities, token } = $('Build FB Batch').item.json;
const batchResponses = $input.item.json; // array dari FB batch

// Pastikan batchResponses adalah array
const responses = Array.isArray(batchResponses) ? batchResponses : [batchResponses];

const triggered = [];

for (let i = 0; i < responses.length; i++) {
  const resp = responses[i];
  if (!resp || resp.code !== 200) continue;

  let body;
  try { body = JSON.parse(resp.body); } catch { continue; }

  const insights = body?.data?.[0];
  if (!insights) continue;

  const entityId = entities[i];

  // Extract metrics
  const spend = parseFloat(insights.spend || 0);
  const conversions = parseFloat(
    insights.actions?.find(a => a.action_type === 'purchase')?.value || 0
  );
  const cpa = conversions > 0 ? spend / conversions : 0;
  const roas = parseFloat(insights.purchase_roas?.[0]?.value || 0);
  const purchaseValue = parseFloat(
    insights.action_values?.find(a => a.action_type === 'purchase')?.value || 0
  );
  const roi = spend > 0 ? (purchaseValue - spend) / spend : 0;

  const metrics = { spend_today: spend, conversions, cpa, roas, roi };

  // Evaluate all conditions (AND logic)
  const conditions = rule.conditions || [];
  const allMet = conditions.length > 0 && conditions.every(c => {
    const val = metrics[c.metric];
    if (val === undefined || val === null) return false;
    switch (c.operator) {
      case 'gt':  return val > c.value;
      case 'lt':  return val < c.value;
      case 'gte': return val >= c.value;
      case 'lte': return val <= c.value;
      case 'eq':  return val === c.value;
      default:    return false;
    }
  });

  if (allMet) {
    triggered.push({
      json: {
        rule,
        entityId,
        metrics,
        token,
      }
    });
  }
}

// Kalau tidak ada yang triggered, return empty (workflow stop di sini)
return triggered.length > 0 ? triggered : [{ json: { noTrigger: true } }];
```

### Node 12 — Execute FB Action

- Type: **Code**
- Name: `Build FB Action`

```javascript
const { rule, entityId, metrics, token } = $('Evaluate Rules').item.json;

let body = {};

if (rule.action === 'pause') {
  body = { status: 'PAUSED', access_token: token };
} else if (rule.action === 'enable') {
  body = { status: 'ACTIVE', access_token: token };
} else if (rule.action === 'scale_budget') {
  const scalePct = rule.action_params?.scale_pct || 20;
  const cap = rule.action_params?.cap || 500;
  // Note: current_budget harus di-fetch dulu — simplified untuk MVP
  // Untuk sekarang, set ke cap value dalam cents
  body = { daily_budget: cap * 100, access_token: token };
}

return [{ json: { entityId, body, rule, metrics, token } }];
```

- Type: **HTTP Request**
- Name: `Call FB API`
- Method: `POST`
- URL: `https://graph.facebook.com/v21.0/{{ $json.entityId }}`
- Body Content Type: `Form Data`
- Fields: `status` = `{{ $json.body.status }}`, `access_token` = `{{ $json.token }}`

## Workflow 2: Schedule Check

**Trigger:** Every 1 minute
**Purpose:** Turn campaigns ON/OFF berdasarkan jadwal dan waktu sekarang (Eastern Time)

---

### Node 1 — Schedule Trigger

- Every **1 Minute**

---

### Node 2 — Get Active Schedules

- **HTTP Request** GET `{{ $vars.ZUCKCANNON_URL }}/api/rules-engine/active-schedules`

---

### Node 3 — Split Schedules

- **Split In Batches**, size 1

---

### Node 4 — Evaluate Time Window

- Type: **Code**

```javascript
const schedule = $input.item.json;

// Get current time in schedule's timezone
const now = new Date();
const formatter = new Intl.DateTimeFormat('en-US', {
  timeZone: schedule.timezone || 'America/New_York',
  weekday: 'narrow',
  hour: '2-digit',
  minute: '2-digit',
  hour12: false,
});

const parts = formatter.formatToParts(now);
const hour = parseInt(parts.find(p => p.type === 'hour').value);
const minute = parseInt(parts.find(p => p.type === 'minute').value);
const weekdayMap = { 'M': 1, 'T': 2, 'W': 3, 'Th': 4, 'F': 5, 'S': 6, 'Su': 7 };
const currentDay = now.toLocaleDateString('en-US', {
  timeZone: schedule.timezone || 'America/New_York',
  weekday: 'short'
});
// Convert to 1=Mon ... 7=Sun
const dayNum = ['Sun','Mon','Tue','Wed','Thu','Fri','Sat'].indexOf(currentDay);
const dayMon1 = dayNum === 0 ? 7 : dayNum; // Convert Sun=0 to Sun=7

const currentMinutes = hour * 60 + minute;
const [startH, startM] = schedule.start_time.split(':').map(Number);
const [endH, endM] = schedule.end_time.split(':').map(Number);
const startMinutes = startH * 60 + startM;
const endMinutes = endH * 60 + endM;

const days = schedule.days || [];
const inWindow = days.includes(dayMon1)
  && currentMinutes >= startMinutes
  && currentMinutes < endMinutes;

return [{
  json: {
    ...schedule,
    inWindow,
    campaign_ids: schedule.campaign_ids || [],
  }
}];
```

---

### Node 5 — Split Campaign IDs

- Type: **Code**
- Name: `Split Campaigns`

```javascript
const { campaign_ids, inWindow, token, id: scheduleId } = $input.item.json;
return campaign_ids.map(campaignId => ({
  json: { campaignId, inWindow, token, scheduleId }
}));
```

---

### Node 6 — Get Campaign Status from FB

- **HTTP Request** GET
- URL: `https://graph.facebook.com/v21.0/{{ $json.campaignId }}?fields=status&access_token={{ $json.token }}`

---

### Node 7 — Decide Action

- Type: **Code**

```javascript
const { inWindow, token, scheduleId } = $('Split Campaigns').item.json;
const campaignId = $('Split Campaigns').item.json.campaignId;
const currentStatus = $input.item.json.status;

const shouldBeActive = inWindow;
const isCurrentlyActive = currentStatus === 'ACTIVE';
const needsChange = shouldBeActive !== isCurrentlyActive;

return [{
  json: { campaignId, shouldBeActive, needsChange, currentStatus, token, scheduleId }
}];
```

---

### Node 8 — Needs Change? (IF)

- Condition: `{{ $json.needsChange }}` **equals** `true`

---

### Node 9 — Check Rule Exemption

- **HTTP Request** GET
- URL: `{{ $vars.ZUCKCANNON_URL }}/api/rules-engine/exemptions/check?rule_id=0&entity_id={{ $json.campaignId }}`

> `rule_id=0` = check apakah campaign ini sedang di-pause oleh rule manapun

---

### Node 10 — Rule Override? (IF)

- Condition: `{{ $json.exempt }}` **equals** `false`
- True branch → Node 11 (apply schedule)
- False branch → end (rule sedang paused, skip)

---

### Node 11 — Apply Schedule

- **HTTP Request** POST
- URL: `https://graph.facebook.com/v21.0/{{ $('Decide Action').item.json.campaignId }}`
- Body Form Data:
  - `status`: `{{ $('Decide Action').item.json.shouldBeActive ? 'ACTIVE' : 'PAUSED' }}`
  - `access_token`: `{{ $('Decide Action').item.json.token }}`

---

### Node 12 — Log Schedule Action

- **HTTP Request** POST `{{ $vars.ZUCKCANNON_URL }}/api/rules-engine/log`
- Body JSON:
```json
{
  "entity_type": "campaign",
  "entity_id": "{{ $('Decide Action').item.json.campaignId }}",
  "action_taken": "{{ $('Decide Action').item.json.shouldBeActive ? 'enabled' : 'paused' }}",
  "trigger_data_json": "{\"source\": \"schedule\", \"schedule_id\": {{ $('Decide Action').item.json.scheduleId }}}",
  "is_dry_run": 0
}
```

## Workflow 3: Daily Digest + Token Health

**Trigger:** Daily jam 23:55 Eastern
**Purpose:** Summary harian ke Telegram, cek token expiry

---

### Node 1 — Schedule Trigger

- Cron expression: `55 23 * * *`
- Timezone: **America/New_York**

---

### Node 2 — Get Today's Logs

- **HTTP Request** GET
- URL: `{{ $vars.ZUCKCANNON_URL }}/api/rules-engine/logs?date={{ new Date().toISOString().split('T')[0] }}&limit=500`

---

### Node 3 — Aggregate Stats

- Type: **Code**

```javascript
const logs = $input.all().map(i => i.json);

const rulesFired = logs.filter(l => !l.is_dry_run).length;
const paused = logs.filter(l => l.action_taken === 'paused').length;
const scaled = logs.filter(l => l.action_taken === 'scaled').length;
const dryRun = logs.filter(l => l.is_dry_run).length;
const date = new Date().toLocaleDateString('en-US', {
  timeZone: 'America/New_York',
  month: 'short', day: 'numeric', year: 'numeric'
});

return [{ json: { date, rulesFired, paused, scaled, dryRun, total: logs.length } }];
```

---

### Node 4 — Send Digest to Telegram

- **HTTP Request** POST
- URL: `https://api.telegram.org/bot{{ $vars.TELEGRAM_BOT_TOKEN }}/sendMessage`
- Body JSON:
```json
{
  "chat_id": "{{ $vars.TELEGRAM_CHAT_ID }}",
  "text": "📊 *Daily Digest — {{ $json.date }}*\n\nRules Fired: {{ $json.rulesFired }}\nPaused: {{ $json.paused }}  |  Scaled: {{ $json.scaled }}\nDry Run Only: {{ $json.dryRun }}\n\nSystem: ✅ OK",
  "parse_mode": "Markdown"
}
```

---

### Node 5 — Get Tokens

- **HTTP Request** GET `{{ $vars.ZUCKCANNON_URL }}/api/rules-engine/tokens`

---

### Node 6 — Check Token Expiry

- Type: **Code**

```javascript
const tokens = $input.all().map(i => i.json);
const warnings = tokens.filter(t => {
  if (!t.expires_at) return false; // non-expiring = fine
  const daysLeft = (new Date(t.expires_at) - new Date()) / 86400000;
  return daysLeft <= 7;
});
return warnings.length > 0
  ? warnings.map(t => ({ json: t }))
  : [{ json: { noWarnings: true } }];
```

---

### Node 7 — Token Warning? (IF)

- Condition: `{{ $json.noWarnings }}` **is not** `true`

---

### Node 8 — Token Warning Telegram

- **HTTP Request** POST Telegram
- Text: `⚠️ *Token Expiring Soon*\nBusiness: {{ $json.business_name }}\nExpires: {{ $json.expires_at }}\n\nRenew at Facebook Business Manager → System Users`

## Workflow 4: Self-monitoring

**Trigger:** Every 5 minutes
**Purpose:** Ping zuckcannon, alert jika down

---

### Node 1 — Schedule Trigger

- Every **5 Minutes**

---

### Node 2 — Ping Zuckcannon

- **HTTP Request** GET
- URL: `{{ $vars.ZUCKCANNON_URL }}/api/rules-engine/health`
- Timeout: `10000` ms
- **Options → On Error:** `Continue` (jangan stop workflow)

---

### Node 3 — Is Up? (IF)

- Condition: `{{ $json.ok }}` **equals** `true`
- True branch → end (all good, do nothing)
- False branch → Node 4

---

### Node 4 — Alert Down

- **HTTP Request** POST Telegram
- Text:
```
🔴 *Zuckcannon Unreachable*
Rules engine is paused — no rules are being evaluated.
Time: {{ new Date().toISOString() }}
Check server immediately.
```

## Testing Checklist

Setelah semua workflow dibuat:

- [ ] **Workflow 1:** Buat satu rule dengan `is_dry_run = 1`, assign ke campaign yang aktif. Jalankan manual (klik Execute). Cek Telegram ada alert "would_have_paused". Cek `/api/rules-engine/logs` ada entry baru.

- [ ] **Workflow 2:** Buat schedule dengan window yang sudah lewat (misal 00:00–00:01). Assign ke campaign aktif. Run manual. Cek campaign di-pause di FB Ads Manager.

- [ ] **Workflow 3:** Run manual. Cek Telegram dapat digest message.

- [ ] **Workflow 4:** Temporarily stop zuckcannon (`Ctrl+C`). Tunggu 5 menit atau run manual. Cek Telegram alert. Restart zuckcannon.

- [ ] **All 4 workflows:** Set ke **Active** (toggle di n8n).
